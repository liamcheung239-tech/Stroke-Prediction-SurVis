## Data Update Instructions

To update the literature data, run the following command in the terminal:

```bash
cd /Users/liam/Desktop/Stroke-Prediction-SurVis
python3 update_data.py
```

Upon successful execution, the following output will be displayed:

```plain text

```

- The literature **bib file** is located in the `bib` folder, named `references.bib`, which contains the 16 papers included in this review\.

- The **SurVis screenshots** are stored in the `survis_screenshot` folder\.
